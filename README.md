# UICOMP Innovation

Working draft pages for innovation at the University of Illinois College of Medicine Peoria (UICOMP). The pages are password-protected: their content is encrypted and opens in the browser after the password is entered.

| Page | |
|---|---|
| [`index.html`](index.html) | Overview |
| [`case-study.html`](case-study.html) | AI Scientist Case Study |
| [`current-state.html`](current-state.html) | Current State |
| [`strategy-map.html`](strategy-map.html) | Strategy Map |

Encrypted with [StatiCrypt](https://github.com/robinmoisson/staticrypt). Entering the password once unlocks all pages in that browser for 30 days.
